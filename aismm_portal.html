How to Operate the Full-Stack AISMM System

Follow these simple commands to start both the FastAPI Python backend and the Vite React frontend on your local machine or in Docker.

1

Option A: Run Full Stack with Docker Compose (1-Command Launch)

Starts PostgreSQL, Redis, FastAPI Backend, and React Frontend in synchronized containers.

make docker-up

• Frontend UI: http://localhost:3000
• Backend Swagger API: http://localhost:8000/docs

2

Option B: Run Backend & Frontend Locally

Terminal 1 (Backend API):

source .venv/bin/activate && uvicorn backend.app.main:app --reload

Terminal 2 (React Studio Frontend):

cd frontend && npm run dev

• Open in browser: http://localhost:5173

3

Running the 194 Automated Verification Tests

Execute all 21 test suites verifying all 5 platform adapters, 8 AI engines, and security hardening:
